# Bluegrass Dynasty (working title)

A single-player thoroughbred racing management sim with RPG progression, in 8-bit pixel art, for the browser. Built with TypeScript, Phaser 3 and Vite. The full brief is in docs/BRIEF.md. Right now only the 256x240 display frame exists.

## Commands

- `npm run dev` starts the dev server.
- `npm test` runs every test once and exits.
- `npm run lint` lints the repo.
- `npm run typecheck` type-checks without emitting files.
- `npm run build` writes a production build to `dist/`.

## Node version

Use the version in `.nvmrc` (for example `nvm use`). CI reads the same file.
